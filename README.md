# exam-radar · 笔试雷达

把散落在招聘邮箱里的笔试、测评邀请，整理成一张清晰、可编辑的秋招笔试时间表。

exam-radar（笔试雷达）是一个**本地运行**的小工具：通过 IMAP 只读连接邮箱，在本机识别笔试邮件，抽取公司、岗位、考试时间、截止时间、考试平台、考试链接和口令，再用一个中文看板展示与跟踪。默认不把邮件内容发送到任何云端服务。

---

## 能做什么

- **读取招聘邮箱**：内置 QQ、网易 163、网易 126、Gmail 和自定义 IMAP 配置。
- **自动识别笔试邮件**：区分笔试邀请、在线测评、笔试提醒，过滤面试通知、笔试成绩、备考资料和招聘广告。
- **抽取关键信息**：
  - 公司与岗位
  - 考试开始 / 结束时间与作答时长
  - 确认或作答截止时间
  - 考试平台与考试链接
  - 线上 / 线下形式、考试地点、考试口令
  - 邮件中的设备或身份核验提醒
- **提醒去重与改期更新**：同一场笔试的邀请和提醒邮件会合并；主题包含“时间变更 / 改期 / 调整”的邮件会更新原记录。
- **看板与倒计时**：下一场笔试、未来 7 天日程、截止提醒、待确认信息，一屏看清。
- **手动修正**：所有识别字段都能编辑，支持标记完成、取消、忽略和删除。
- **示例模式**：还没连接邮箱时，可以先载入 5 条示例记录查看完整效果。
- **自动检查**：应用运行期间，可按设置每 30 分钟检查一次新邮件（每个邮箱可单独关闭）。

## 快速开始

### Windows

双击 **`start.bat`**，首次运行会自动创建 `.venv` 并安装依赖。启动后会自动打开浏览器：

```text
http://127.0.0.1:8000
```

### macOS / Linux

```bash
bash start.sh
```

### 手动启动

要求 Python 3.10 或更高版本。

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

如果不想自动打开浏览器：

```bash
EXAM_RADAR_NO_BROWSER=1 python run.py
```

## 连接邮箱

在「邮箱」页面选择邮箱类型、填写邮箱地址和授权码，然后点击「测试连接并添加」。

> 这里需要的是**授权码 / 应用专用密码**，通常不是网页登录密码。

### QQ 邮箱

1. 登录 QQ 邮箱网页版，进入「设置 → 账号」。
2. 开启「IMAP/SMTP 服务」。
3. 按提示生成授权码，把 16 位授权码填入笔试雷达。

### 网易 163 / 126 邮箱

1. 登录网页版，进入「设置 → POP3/SMTP/IMAP」。
2. 开启 IMAP 服务并获取客户端授权码。
3. 首次使用可能需要按网页提示完成短信验证。

### Gmail

1. 在 Google 账号中开启两步验证。
2. 创建「应用专用密码」，将 16 位密码填入笔试雷达。
3. 根据所在网络环境，IMAP 连接可能还需要可用的国际网络访问。

### 自定义 IMAP

- 仅支持 **SSL/TLS 加密的 IMAP**，通常端口为 `993`。
- 默认文件夹是 `INBOX`。如果学校邮箱把邮件放在其他文件夹，可在自定义配置中修改。
- 不支持仅允许 OAuth 的邮箱（例如多数 Microsoft 365 企业账号）。如果你的邮箱只提供 OAuth 登录，暂时无法直接接入。

连接成功后会自动触发第一次同步。第一次默认检查最近 30 天的最多 300 封邮件；后续同步按 IMAP UID 增量检查。可以在连接时调整首次同步范围。

## 使用建议

- 优先使用你投递岗位最多的邮箱。
- 连接后先看「待确认」：有些邮件只给出考试日期而没有具体开始时间，或公司名称写在正文里，工具会提示你补全。
- 邮件中的考试链接、口令和提醒会保存在详情面板里，点击「考试入口」即可打开。
- 标记完成、忽略错误识别、删除无关记录都不会影响邮箱中的原始邮件。
- 自动同步需要应用保持运行。关闭应用后不会在后台驻留。

## 数据与隐私

- 看板默认只监听 `127.0.0.1`，不对局域网或公网开放。
- 邮箱使用 **IMAP 只读访问**，不会标记已读、发送、修改或删除邮件。
- 只有被识别为笔试相关的邮件正文会保存在本地 SQLite；所有扫描过的邮件只记录去重用的消息指纹和识别结果，不保存正文。
- 授权码使用 Fernet 加密后保存：
  - 数据库：`data/exam-radar.db`
  - 本地密钥：`data/.secret.key`
  - 日志：`data/exam-radar.log`
- 邮件内容和识别过程默认不经过任何第三方模型或云端服务。
- 加密密钥与数据库放在同一台机器上，主要用于避免明文保存授权码。若设备本身已失守，本地加密不能提供额外的强隔离。
- 如果删除 `.secret.key`，已保存的授权码将无法解密，需要重新输入；邮件识别记录仍会保留。
- 想完全清空本地数据：先停止应用，再删除 `data/` 目录。

> 不要把 `EXAM_RADAR_HOST` 改成 `0.0.0.0` 后直接暴露到公网。应用没有登录验证。

## 可选配置

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `EXAM_RADAR_DATA_DIR` | `./data` | 数据库、密钥和日志目录 |
| `EXAM_RADAR_HOST` | `127.0.0.1` | 监听地址；建议保持本机回环地址 |
| `EXAM_RADAR_PORT` | `8000` | 监听端口 |
| `EXAM_RADAR_AUTO_SYNC_MINUTES` | `30` | 自动同步检查间隔（最小 5 分钟） |
| `EXAM_RADAR_SECRET_KEY` | 空 | 用自定义口令派生本地加密密钥；设置后需保持一致 |
| `EXAM_RADAR_DISABLE_SCHEDULER` | 空 | 设为 `1` 可关闭后台自动同步线程 |
| `EXAM_RADAR_NO_BROWSER` | 空 | 设为 `1` 时启动后不自动打开浏览器 |

旧版的 `EXAMHELPER_*` 环境变量仍会作为回退读取，已有数据会在首次启动时自动复制到 `data/exam-radar.db`，原数据库保留作为备份。

示例：

```bash
# 使用独立的数据目录和端口
EXAM_RADAR_DATA_DIR=/path/to/exam-data EXAM_RADAR_PORT=8765 python run.py
```

## 识别范围与已知限制

- 识别采用本地规则与正则，不依赖大模型。常见招聘邮件格式覆盖得较好，但非标准模板仍可能需要手动修正。
- 时间按 **北京时间（Asia/Shanghai）** 理解与显示。海外考试的具体时区需要在备注中自行确认。
- 首次同步最多处理最近 300 封邮件；如果收件箱里积压更多，更早的邮件不会自动回溯。可以在添加新账号时调整同步范围。
- 只同步一个文件夹（默认 `INBOX`），不会遍历所有自定义文件夹。
- 邮件附件不会被解析；如果笔试信息只在 PDF/图片附件里，需要在备注中自行补充。
- 自动同步仅为应用运行时的定时检查，不是系统后台服务。
- 无法同步已归档或已移出收件箱的邮件。

安装开发依赖：

```bash
pip install -r requirements-dev.txt
```


## 常见问题

### 认证失败

- QQ：确认已开启 IMAP，并使用 16 位授权码，不是 QQ 密码。
- 163 / 126：确认已开启 IMAP 并使用客户端授权码；首次使用可能需要短信验证。
- Gmail：确认已开启两步验证，并使用应用专用密码。
- 检查邮箱服务商是否关闭了第三方客户端 IMAP 登录。

### 连接成功但识别不到邮件

- 确认邮件在收件箱（`INBOX`）里，且在同步范围内。
- 确认笔试信息在邮件正文里，而不是只在附件里。
- 点击「立即同步」重新检查；已经被扫描过且判定为非笔试的邮件不会重复处理。
- 如属于特殊格式，可手动添加一条记录。

### 页面打不开

- 确认启动窗口没有报错，且端口没有被其他程序占用。
- 可在启动脚本中修改 `EXAM_RADAR_PORT` 后重试。
- 查看 `data/exam-radar.log` 获取同步和接口错误。

### 忘记授权码

删除 `data/` 目录会连同所有笔试记录一起清空。若只想重置授权码，删除 `data/.secret.key` 后重新打开应用，再在邮箱设置中更新授权码；这不会删除笔试记录，但所有已保存授权码都需要重新输入。
